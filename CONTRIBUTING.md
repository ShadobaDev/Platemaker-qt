# Contributing

Thank you for your interest in contributing to Platemaker!

## Contributor License Agreement

By opening a pull request you agree to the [Contributor License Agreement](CLA.md).
This allows the project to be offered under additional license models in the future
while keeping your contributions permanently credited.

## Before you start

The project is not looking for collaborators, but that is not a rule against contributions: for
anything significant, open an issue first and ask whether it fits.

- **Extending the strip editor** (a tool, a balloon shape, a kind of object):
  [docs/EXTENDING.md](docs/EXTENDING.md), which says which files each one touches.
- **How the rest is put together:** the wiki's
  [Development](https://github.com/ShadobaDev/Platemaker-qt/wiki/Development) pages. They cover
  architecture, the strip editor's vocabulary, building, commit messages and spelling.
- **Building:** [README](README.md#building).

## Submitting a pull request

1. Fork the repository and create a branch from `main`.
2. Make your changes and ensure the project builds cleanly.
3. Open a pull request with a clear description of what and why.
